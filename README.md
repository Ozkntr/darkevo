# Darkevo

Darkevo resmi oyun sitesi. Next.js, Türkçe / İngilizce dil desteği.

## Geliştirme

```bash
npm install
npm run dev
```

Tarayıcıda [http://localhost:3000](http://localhost:3000) adresini açın.

- `TR / EN` dil menüsü seçimi `localStorage` içinde saklanır (`darkevo-locale`).
- Sayfalar: ana sayfa, wiki, destek, ücretsiz oyna.
